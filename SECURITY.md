# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to the repository maintainer or open a private security advisory on GitHub.

Please include:
1. Detailed steps to reproduce the vulnerability.
2. Affected browser versions and operating system.
3. Potential impact or exploit scenarios.

We take security seriously and will review your report within 48 hours.
